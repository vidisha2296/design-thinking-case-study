# Design Thinking Case Study

This project is a full-stack application built as part of a design thinking assessment.

## Tech Stack

Frontend:
- Next.js (React framework)
- Node.js

Backend:
- Python FastAPI

Infrastructure:
- Docker for containerization
- Render for deployment
- PostgreSQL (planned)

## Project Structure

- frontend → Next.js UI application
- backend → FastAPI REST services
- docker-compose → Local multi-service setup

## Objective

The goal of this project is to demonstrate:
- Product thinking
- System design ability
- Full-stack development
- Containerization & deployment skills
- Clean engineering practices

## Setup Instructions

### Run locally

docker compose up --build

### Backend

Runs on:
http://localhost:8000

### Frontend

Runs on:
http://localhost:3000

## Deployment

Application is designed to be deployed on Render using Docker-based web services.
